Everything the first DAW session against 1.4.0 turned up, plus a full code
review. Verified in Live 12 (VST3) and Logic Pro (AU) on 2026-08-17.

**Stopping actually stops** — a Stop no longer leaves notes ringing in the
built-in synth, and the Stop button now works while the host transport is
rolling in sync mode.

**Sync-mode correctness**: on-grid events were being dropped at triplet
units, reseeding a voice while synced no longer replays it from step 0, and a
same-sample note-off is now emitted before a same-note note-on.

**Score, register, export**: the score span is bounded by what's actually on
screen, register octave 8 keeps all twelve pitch classes, drag-export works
in Logic, and Save writes atomically so a failed save can't cost you the
file you had.

A golden determinism snapshot and an audio-thread allocation guard were
added. pluginval now runs in CI against the AU. Test suite: engine 76 → 100
cases, plugin 79 → 112.
