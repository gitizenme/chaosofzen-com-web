Two ways to steer the generator instead of only re-rolling it.

**Scale-degree controls.** A global **Scale** and **Scale Root**, plus a
per-voice override in each voice's disclosure. Ten scales — Off, Major,
Dorian, Phrygian, Lydian, Mixolydian, Minor, Locrian, Pentatonic and Whole
Tone — and each voice can either follow the global setting or pick its own.
Scale starts at **Off**, which is what every project saved before this release
already does, so nothing you have open changes pitch when you update.

**Randomize.** A **Randomize All** button with an **Amount** dial that blends
from where each parameter currently sits rather than jumping, an **Undo**, and
five locks — Wave, Rate, Unit Range, Register, Jitter — that hold one
parameter still while everything around it moves. Each voice has its own
Randomize too.

**Sessions saved by a newer version now say so.** Seriatim stamps a version
into what it writes. Open one of those in an older build and the About panel
tells you settings were dropped, instead of the older build discarding them
silently and losing them the next time you save. Older builds still open these
sessions normally.

**Also:** Seriatim's own icon, palette and type throughout, a branded
installer, and the control panel's controls grouped under header bands.

Not included: a Windows build — it is built and tested but not yet signed, so
it ships in a later release. No Linux build, no Homebrew cask, no in-plugin
update check.
