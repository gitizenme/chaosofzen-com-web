Two features that both answer the same complaint: getting Seriatim's four
voices into something that will play them.

**MPE output.** A new MIDI Out control chooses how the four voices leave the
plugin. Channel-per-voice remains the default; MPE mode emits one lower
zone — master on channel 1, members on 2–16 — with every note on its own
member channel and glissandi carried as pitch-bend ramps instead of chromatic
runs.

**Seriatim MIDI FX** (`aumi SrMF CofZ`, AU only) is the same generator built
for Logic's MIDI FX slot — the one place in Logic a generator can drive the
instrument beneath it, since a software-instrument channel strip's own MIDI
output has nowhere to go. Host-verified in Logic Pro 12.3.1.

Releases are now built and published by CI from a pushed tag, and this is the
first release with binaries attached — ad-hoc signed only, not notarized.

Test suite: engine 106 → 130 cases, plugin 115 → 131.
