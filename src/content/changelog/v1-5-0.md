Seriatim's first release with a real installer. Distribution and MIDI input
landed independently and happen to ship together.

**Download and double-click, no terminal required.** Every release from now
on is a Developer ID–signed, Apple-notarized, stapled `.dmg` containing a
`.pkg` installer. The installer carries its own uninstaller
(`Uninstall Seriatim.sh`, next to the pkg inside the dmg).

**MIDI input.** Seriatim's built-in synth can now be played live from an
external MIDI or MPE controller, independent of the generative engine. A
gated envelope mode holds notes of unknown length open until released. A
**MIDI Thru** toggle and a **MIDI In Bend Range** control were added to both
editors.

**Fixed:** a dead parameter attachment now fails the test suite instead of
doing nothing, MIDI FX editor polish and coverage, and a handful of
correctness fixes surfaced by the new MIDI-input work.

Test suite: engine 130 → 154 cases, plugin 131 → 157.

Not included: Windows and Linux builds, a Homebrew cask, an in-plugin update
check.
