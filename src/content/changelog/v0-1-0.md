Ekphrasis reads an image as a spectrogram and resynthesizes it in real time. A
reading head sweeps the picture in musical time: each row of pixels is a
frequency band, each column a moment, and how bright a pixel is decides how
loudly that band sounds.

**Griffin-Lim phase reconstruction** is what makes the result follow the image
rather than merely being triggered by it — an iterative synthesise/re-analyse
loop that recovers the phase a picture cannot store. Measured fidelity climbs
from 0.593 after one iteration to 0.895 after sixty.

**Shaping how the picture is read.** Reading paths run horizontal, vertical,
radial or spiral, with even, accelerando, rallentando or breathing pacing. The
frequency axis is logarithmic or linear, with an optional musical-scale
quantiser. An ink curve — invert, threshold, contrast — decides what counts as
sound, drawn live on the displayed image so you set it by eye rather than by
number.

**Playing it.** Control is monophonic MIDI: a held note transposes the spectrum
and gates the output. With no note held Ekphrasis is silent — a **Hold** toggle
sounds the image with no controller, armed track or MIDI routing. Note that the
standalone app opens with no MIDI input on macOS until you enable one under
Options → Audio/MIDI.

**Download and double-click, no terminal required.** A Developer ID–signed,
Apple-notarized, stapled `.dmg` containing a `.pkg` installer, which places the
AU, the VST3 and the standalone app. The installer carries its own uninstaller,
`Uninstall Ekphrasis.sh`, beside the pkg inside the disk image; it removes all
three components and forgets their `pkgutil` receipts, so a later reinstall does
not report "already installed" against files that are gone.

Verified on every push: 98 engine test cases across 123,360 assertions, 26
plugin test cases, `pluginval` at strictness 10 against both the AU and the
VST3, and a proof that the audio thread allocates nothing on a cold cache.
Universal binary, `x86_64 arm64`. macOS 11.0 or later.

Not included: Windows and Linux builds, polyphony, an in-plugin update check.
